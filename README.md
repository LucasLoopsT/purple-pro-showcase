# Bloom Portfolio

tenho a ideia de criar um site de portfolio para uma profissional da area de psicologia/RH. O Esqueleto do site já está pronto em HTML/CSS/JS puro, mas preciso que melhore ele pois o design ainda está muito simples e sem identidade/fluidez no conteúdo para uma leitura leve que leve as informações da candidata a vagas de emprego como um diferencial. Existem ambiguidades (botão de curriculo 2 vezes no header), seções ruins ao meu ver (competencias ocupa muito espaço e não agrega muito valor)

A maior parte das informações de currículo dela estão aí. O que não tiver pode utilizar mocks e criar o novo design que converse com a área do RH. Gosto de cores lights e com tons em lilás/roxo/violeta.
